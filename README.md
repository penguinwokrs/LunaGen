# Luna Matching Auto Message Bot

このスクリプトは、SMマッチングサイト「Luna」において、ログインから相手のプロフィールに合わせたメッセージ生成・送信までを自動化するツールです。

## 機能

1.  **自動ログイン**: 提供されたIDとパスワードを使用して自動的にログインします。
2.  **ペルソナ抽出**: 自身のプロフィールページ（`/profile`）から自己紹介文を取得します。
3.  **プロフィール分析**: 指定した送信対象のプロフィールを解析します。
4.  **メッセージ生成**: 自身と相手の情報を元に、共感を呼ぶメッセージのドラフトを作成します。
5.  **メッセージ送信**: 相手のページのメッセージ入力欄にテキストを入力します。
    *   *注: デフォルトでは安全のため送信ボタンのクリックは無効化されています。*

## インストール

Python 3.7以上が必要です。

```bash
# ライブラリのインストール
pip install -r requirements.txt

# Playwright用ブラウザのセットアップ
playwright install chromium
```

## 使い方

送信対象のプロフィールURLを引数に指定して実行してください。

```bash
uv run python luna_bot.py https://luna-matching.com/user/show/140135
```

## 設定の変更

### ログイン情報の変更
`luna_bot.py` 内の以下の変数を書き換えてください。
- `DEFAULT_EMAIL`
- `DEFAULT_PASSWORD`

### 自動送信の有効化
誤送信を防ぐため、メッセージの入力までは行いますが「送信ボタン」のクリックはコメントアウトされています。
実際に送信を行う場合は、`send_message` 関数内の以下の行を探してコメントアウトを解除してください。

```python
# send_btn.click()  <-- このコメントを外すと実際に送信されます
```
